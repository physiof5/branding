# 마이펫 추후 업데이트 메모

> 상태: 아이디어 정리 단계 · 아직 개발 안 함

## 1. 놀아주기 미니게임 — 공 던지기
- 화면 아래 공을 손가락으로 **위로 튕겨 던지면** 펫이 달려가서 받는다.
- 펫 앞에 **줄어드는 원(타이밍 링)** 이 나타난다.
  - 원이 작을 때 던질수록 판정이 좋다: `Nice` → `Great` → `Excellent`
  - 원의 **정가운데**에 맞히면 보너스
- 공을 빙글빙글 돌린 뒤 던지면 **커브볼** → 펫이 더 좋아함(행복 추가 보너스, 반짝이 연출)
- 결과에 따라 행복·친밀도 상승량이 달라짐, 연속 성공 콤보
- 빗나가면 공이 데굴데굴 굴러가고 펫이 아쉬워하는 모션

## 2. 씻기기 미니게임 — 샴푸 · 솔 · 물
- 산책·시간 경과로 펫 몸에 **얼룩/진흙 자국**이 생김 (청결 수치와 연동)
- 도구 3단계
  1. 🧴 **펫샴푸**: 문지르면 거품이 생김
  2. 🪮 **솔**: 거품을 털 구석구석 문질러 얼룩 제거
  3. 🚿 **물(샤워기)**: 거품을 헹궈 냄
- 화면에 남은 얼룩 % 표시, 다 씻기면 몸을 털며 물방울 튀기는 마무리 모션
- 고양이는 물을 싫어해서 빨리 끝내야 행복 감소가 적음

## 3. 입장 환영 모션
- 마이펫 화면에 들어오면 펫이 반겨주는 모션 (예: 강아지는 꼬리 흔들며 달려오기, 점프, 뱅글뱅글 돌기 / 고양이는 기지개·몸 비비기)
- 오래 안 들어왔을 때 / 배고플 때 / 기분 좋을 때 등 상태별 다른 인사
