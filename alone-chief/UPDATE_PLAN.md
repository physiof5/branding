# 나홀로 실장 · 고득점 업데이트 기획안

> 상태: **2안(악세서리) 적용 완료** (1위 2,530점 도달) · 1안(어빌리티)은 대기
> 적용 내역: 손 소품 → 🎒 악세서리 탭 분리, 11종 3D 디자인 + 능력, 선택 시 능력 설명, 랭킹 1~3위 악세서리 아이콘.
> 변경점: 📯 호루라기 → 🔔 호출벨(30초마다 대기 환자 1명 자동 호출), 🎧 헤드셋은 20초마다 자동 원격 마무리, 🔫 마사지건은 도수 점수 +20% 포함.

## 적용 순서
1. **2안(악세사리)** 먼저 적용 — 기존 손 소품·꾸미기 화면 재사용, 작업이 가볍다.
2. 반응이 좋으면 **1안(어빌리티)** 추가 — 게임 전 선택(악세사리) + 게임 중 선택(어빌리티) 조합.
3. 업데이트 시점에 **랭킹 시즌을 새로 시작**하거나 "업데이트 이후 랭킹"을 따로 표시한다.
4. 서버 점수 상한(현재 6,000점)을 새 이론 최대치에 맞춰 다시 계산한다. 예상 최고 점수: 4,500~5,500점.

## 1안 · 어빌리티 (남은 시간 2:00, 1:00에 3장 중 1장 선택)

### 연출
- 바로 카드를 보여주지 않고 **약 2초간 기대감 연출** 후 공개한다.
  - 예: 게임이 멈추고 화면이 어두워짐 → "레벨 업!" 배너 → 뒤집힌 카드 3장이 흔들리며 빛남(두근두근 효과음) → 한 장씩 뒤집히며 공개(뿅-뿅-뿅) → 등급별 테두리 색(일반/희귀/전설) 표시.
- 선택 후 짧은 적용 이펙트, 게임 재개 전 1초 카운트.

## 랭킹 표시
- 랭킹 **1·2·3위** 옆에 그 기록에서 장착한 **악세사리 아이콘**을 표시한다.
- 서버 `scores` 테이블에 `accessory` 값을 함께 저장해야 한다(업데이트 시 마이그레이션 추가).
