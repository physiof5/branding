# 🍑 공부는 엉덩이 싸움

> 3초 안에 고르는 1:1 턴제 **심리전 엉덩이 배틀** — 3D 웹 게임 (React Three Fiber)

교실에서 연구소까지, 티어가 오를수록 무대가 바뀌는 엉덩이 밀치기 대결.
두 사람은 **서로 등지고(엉덩이를 마주하고)** 서서, 매 턴 **기 모으기 / 피하기 / 공격** 중 하나를 동시에 고릅니다. 판정 순간 카메라가 줌·쉐이크·앵글 전환으로 타격감을 살려 줍니다.

## 바로 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (HMR) |
| `npm test` | 판정 규칙 · AI · 랭크 · 배틀 상태 머신 · 모드/보상 단위 테스트 (Vitest) |
| `npm run build` | 정적 배포용 빌드 → `dist/` |
| `npm run build:single` | JS/CSS 를 HTML 하나에 인라인 → `dist-single/index.html` (파일 하나로 공유/데모) |

Node 22+ 권장. 외부 에셋 없이(사운드도 Web Audio 합성) 바로 동작합니다.

개발용 URL 옵션: `?turnaround` 캐릭터 4방향 턴어라운드(레퍼런스 비교용) · `?wide` 연출 컷 없이 와이드 카메라 고정(포즈 확인용)

| | 기 모으기 | 피하기 | 공격 | 아이템 |
| --- | --- | --- | --- | --- |

`ESC` 일시정지 · 모바일은 화면 버튼 (클래식 1v1: 왼쪽 1P / 오른쪽 2P, 누른 버튼은 상대에게 안 보임)

## 게임 모드

| 모드 | 내용 |
| --- | --- |
| 🏆 **클래식 랭크전** | 개인/2인 랭크 (Solo/Duo Queue). 솔로 1:1, 또는 파트너 1명과 2:2 **릴레이** 로 트로피·티어를 올림 |
| 🤝 **자유 랭크전** | Flex Queue. 1~3인 파티를 짜서 팀 단위 릴레이로 경쟁 (트로피는 솔로/듀오와 별도) |
| 🎯 **클래식 도전** | **하루 10판**. 이길 때마다 아이템(방어막·먹물 폭탄·기폭제 중 1개) 지급, 상대 AI 한 단계 강함 |
| 👥 **클래식 1v1** | 한 기기 2인 친선전. 무대 직접 선택, 랭크·재화 변동 없음 |

- **릴레이**: 한 명씩 나가 1:1 로 싸우고, 쓰러지면 다음 주자가 이어받음 (이긴 쪽은 남은 체력 유지). 파트너는 AI 또는 같은 기기 친구(자기 차례에 기기를 넘겨받아 조작)
- **전투 준비**: `전투!` 를 누르면 큐/파티 구성과 **기폭제 사용 여부**를 정한 뒤 참가 (기폭제는 시작 화면이 아니라 여기서 결정)
- 🌐 온라인 랭크 매칭은 `src/net` 프로토콜까지 준비 (서버 연결 예정)

## 규칙 요약

- HP 100, 매 턴 **3초** 안에 동시 선택 (못 고르면 💤 멍때리기 = 무방비)
- 상성: **공격 ▶ 기 모으기 ▶ 피하기 ▶ 공격** — 기 모으기는 무방비라 공격을 맞으면 데미지 (기는 그래도 +1)
- 공격 = 뒤로 돌진하며 **엉덩이로 들이받기**, 피하기 = **골반을 앞으로 쭉 빼서** 엉덩이를 쏙 비키기
- 공격 단계는 보유한 기로 자동 결정
  - 기 0~2 **일반 공격** 10
  - 기 3+ **강력 공격** 50 (기 3 소모)
  - 기 10 **필살기** 100 즉사 (기 10 소모, **회피·방어 불가**)
- 동시 공격: 같은 단계는 상쇄, 다른 단계는 높은 쪽이 압도
- 🌙 **야자 타임**: 15턴부터 선택 시간 **1.5초**, 매 턴 두 사람 모두 기 +1 → 후반은 '누가 먼저 필살기를 쏘나' 심리전 (`OVERTIME_TURN` 으로 조절)
- 30턴이 지나면 체력 판정
- 아이템: 🛡️ 방어막(필살기 제외 1회 무효) · 🦑 **먹물 폭탄**(3턴 동안 상대 시야를 먹물로 가림 → 상대는 내 기 게이지가 차는 걸 볼 수 없음, AI 도 멈춘 값만 앎) · ⚡ 기폭제(시작 시 기 +1)

> 밸런스 메모: AI 대 AI 300판 시뮬레이션(`src/game/ai.sim.test.ts`) 기준 KO 종료 ~85%, 평균 ~20턴. 야자 타임 없이 기획 수치만으로는 90% 이상이 30턴 판정까지 늘어져서 추가했습니다.

## 화면

- **시작 페이지** — 스크롤 없는 한 화면, 노란 배경. 좌상단에 프로필(티어·트로피·닉네임·전적), 가운데 무대는 **현재 티어의 랭크 맵** 위에 내 캐릭터 (누르면 꾸미기), 하단에 `모드 변경` · `전투!` · 하단 탭(상점/꾸미기/전투/패스/랭크)
- **트로피 로드** — 티어별 무대·상대 AI 와 50트로피마다 보상 (최고 기록 기준 1회 수령)
- **꾸미기 / 상점 / 로열 패스** — 외형 전용 커스터마이징, 소모 아이템·코스튬 구매, 20레벨 무료/프리미엄 트랙

## 캐릭터

레퍼런스 시트(`기본 캐릭터 디자인.png`: 민머리 · 굵은 눈썹 · 큰 빨간 입술 · 네이비 스크럽 · 사원증)를 측정해 **부위별 함수**로 모델링했습니다 (`src/scene/character/`).

| 부위 | 함수 |
| --- | --- |
| 얼굴(두상) | 높이별 반폭/앞·뒤 깊이 프로파일 → 변형 아이코스피어, 평면 셰이딩 |
| 표정 | 눈썹·눈(하이라이트)·코(쐐기형 + 콧구멍)·볼터치·윗/아랫입술(큐피드 활 + 맞닿는 면) 위치·크기 표 |
| 몸통·어깨 | 슈퍼엘립스 단면 링 로프트 (V넥 · 사원증 · 단 처리) |
| 팔 | 어깨→손목 테이퍼 + 소매, 손 |
| 골반·엉덩이 | 골반 링 로프트 + 엉덩이 볼륨(커스터마이즈) 파라미터 |
| 다리·발 | 다리 링 로프트, 신발 로프트 |

색은 시트에서 측정한 값(`REF_COLORS`), 무광·플랫 셰이딩으로 로폴리 질감을 재현합니다. 체형·키·엉덩이 볼륨은 같은 함수에 비율만 바꿔 적용됩니다.

## 구현된 기능

- **3D 배틀 씬** — 등을 맞댄 스탠스, 엉덩이 들이받기 / 골반 앞으로 빼기 회피 / 기 오라 / 점프 엉덩방아 필살기 / 앞으로 엎어지는 KO / 릴레이 교대 입장
- **카메라 연출** — 공격자 추적 → 임팩트 클로즈업 컷, 회피 정면 컷, 상쇄 탑앵글, 필살기 오빗·로우앵글, KO 오빗, 트라우마 기반 쉐이크 + FOV 펀치 + 히트스톱/슬로모션 (설정에서 흔들림 조절)
- **턴 로직** — 3초(야자 타임 1.5초) 카운트다운, AI(심리전: 상황 판단 + 패턴 학습 + 혼합 전략, 티어별 난이도), 2인 숨김 선택
- **커스터마이징** — 피부색 · 헤어 · 체형 · 키 · **엉덩이 볼륨** · 지역/학교 테마 코스튬 · 오라 이펙트 (외형 전용, 스탯 동일)
- **랭크 & 맵 전환** — 브론즈 교실 → 실버 독서실 → 골드 특목고 → 플래티넘 학원가 → 다이아 캠퍼스 → 마스터 연구소 (티어마다 I/II 단계)
- **사운드** — Web Audio 합성 효과음 + 긴장감 BGM(위기 시 템포 업), 파일로 교체 가능한 구조

설계 상세(폴더 구조 · Zustand 상태 설계 · 상태 머신 · 이벤트 흐름 · 캐릭터 함수)는 **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** 참고.
