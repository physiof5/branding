# 🍑 공부는 엉덩이 싸움

> 3초 안에 고르는 1:1 턴제 **심리전 엉덩이 배틀** — 3D 웹 게임 (React Three Fiber)

교실에서 연구소까지, 티어가 오를수록 무대가 바뀌는 엉덩이 밀치기 대결.
매 턴 **기 모으기 / 피하기 / 공격** 중 하나를 상대와 동시에 고르고, 판정 순간 카메라가 줌·쉐이크·앵글 전환으로 타격감을 살려 줍니다.

## 바로 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (HMR) |
| `npm test` | 판정 규칙 · AI · 랭크 · 배틀 상태 머신 단위 테스트 (Vitest) |
| `npm run build` | 정적 배포용 빌드 → `dist/` |
| `npm run build:single` | JS/CSS 를 HTML 하나에 인라인 → `dist-single/index.html` (파일 하나로 공유/데모) |

Node 22+ 권장. 외부 에셋 없이(사운드도 Web Audio 합성) 바로 동작합니다.

## 조작

| | 기 모으기 | 피하기 | 공격 | 아이템 |
| --- | --- | --- | --- | --- |
| 1P / AI 대전 | `A` `1` | `S` `2` | `D` `3` | `Q` 방어막 · `E` 먹물 |
| 2P (로컬) | `J` `←` | `K` `↓` | `L` `→` | — |

`ESC` 일시정지 · 모바일은 화면 버튼 (로컬 2인: 왼쪽 1P / 오른쪽 2P, 누른 버튼은 상대에게 안 보임)

## 규칙 요약

- HP 100, 매 턴 **3초** 안에 동시 선택 (못 고르면 💤 무방비)
- 상성: **공격 ▶ 기 모으기 ▶ 피하기 ▶ 공격** — 기 모으기는 무방비라 공격을 맞으면 데미지 (기는 그래도 +1)
- 공격 단계는 보유한 기로 자동 결정
  - 기 0~2 **일반 공격** 10
  - 기 3+ **강력 공격** 50 (기 3 소모)
  - 기 10 **필살기** 100 즉사 (기 10 소모, **회피·방어 불가**)
- 동시 공격: 같은 단계는 상쇄, 다른 단계는 높은 쪽이 압도
- 🌙 **야자 타임**: 15턴부터 매 턴 두 사람 모두 기 +1 → 후반은 '누가 먼저 필살기를 쏘나' 심리전 (`OVERTIME_TURN` 으로 조절/비활성)
- 30턴이 지나면 체력 판정

> 밸런스 메모: AI 대 AI 300판 시뮬레이션(`src/game/ai.sim.test.ts`) 기준 KO 종료 ~85%, 평균 ~20턴. 야자 타임 없이 기획 수치만으로는 90% 이상이 30턴 판정까지 늘어져서 추가했습니다.

## 구현된 기능

- **3D 배틀 씬** — 레퍼런스 캐릭터(민머리·굵은 눈썹·빨간 입술·네이비 스크럽·사원증)를 절차적 로폴리로 재현, 뒤돌아 엉덩이로 밀치는 공격 / 좌우 씰룩 회피 / 기 오라 / 점프 엉덩방아 필살기 / KO
- **카메라 연출** — 공격자 추적 → 임팩트 클로즈업 컷, 상쇄 탑앵글, 필살기 오빗·로우앵글, KO 오빗, 트라우마 기반 쉐이크 + FOV 펀치 + 히트스톱/슬로모션 (설정에서 흔들림 조절)
- **턴 로직** — 3초 카운트다운, AI(심리전: 상황 판단 + 패턴 학습 + 혼합 전략, 티어별 난이도), 로컬 2인 숨김 선택
- **커스터마이징** — 피부색 · 헤어 6종 · 체형 · 키 · **엉덩이 볼륨** · 지역/학교 테마 코스튬 · 오라 이펙트 (외형 전용, 스탯 동일)
- **상점 & 아이템** — 방어막(1회 무효) · 먹물 폭탄(상대 선택 시간 1.5초) · 기폭제(시작 시 기 +1)
- **랭크 & 맵 전환** — 브론즈 교실 → 실버 독서실 → 골드 특목고 → 플래티넘 학원가 → 다이아 캠퍼스 → 마스터 연구소
- **로열 패스** — 20레벨 무료/프리미엄 트랙 (코스튬·이펙트·재화·아이템), 프리미엄은 데모 해금
- **사운드** — Web Audio 합성 효과음 + 긴장감 BGM(위기 시 템포 업), 파일로 교체 가능한 구조

설계 상세(폴더 구조 · Zustand 상태 설계 · 상태 머신 · 이벤트 흐름)는 **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** 참고.
